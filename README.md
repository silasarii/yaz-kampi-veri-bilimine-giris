# Veri Bilimine Giriş: Temel Python ve Analiz Çalışmaları

Bu repository; Techcareer.net tarafından düzenlenen Veri Bilimine Giriş Yaz Kampı süresince geliştirilen haftalık alıştırmaları, temel seviye veri manipülasyonu egzersizlerini ve Python'ın yerleşik veri yapıları kullanılarak oluşturulan mini vaka çalışmalarını içermektedir.

## Projenin Kapsamı ve Hedefleri
* Temel programlama yapılarını (döngüler, fonksiyonlar, liste/sözlük işlemleri) pekiştirmek
* Harici kütüphanelere bağımlı kalmadan saf Python (Built-in) ile veri analitiği mantığını kavramak
* Fonksiyonel programlama (`map`, `filter`, `lambda`) ve temel istatistiksel hesaplamaları uygulamak
* Metin işleme ve temel train/test mantığını algoritmik olarak modellemek

## Kullanılan Teknolojiler ve Araçlar
* **Programlama Dili:** Python 
* **Python Yerleşik Modülleri (Built-in):** `statistics` (ortalama, standart sapma), `random` (örneklem/train-test ayrımı)
* **Geliştirme Ortamı:** Jupyter Notebook
